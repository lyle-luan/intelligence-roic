# I-ROIC Model

> Status: Working model
> Updated: 2026-10-06

## 1. Keep ROIC discipline

Classical ROIC is approximately:

    ROIC = NOPAT / Invested Capital

I-ROIC should not abandon that discipline by simply dividing "value" by tokens.

The preferred economic form is:

    I-ROIC = Incremental NOPAT attributable to intelligence
             ------------------------------------------------
             Incremental invested capital required to produce,
             route, validate and execute that intelligence

Where practical disclosure is insufficient, use a hierarchy of proxies rather than pretending precision.

## 2. Three different metrics

### 2.1 Economic I-ROIC

The ultimate metric.

Measures incremental after-tax operating profit against the incremental capital base required to create it.

Possible intelligence-related invested capital includes accelerators and data-center equipment, capitalized model development, networking and storage, dedicated physical automation, software/orchestration capital where economically appropriate, and working capital needed to support AI-created activity.

### 2.2 Intelligence Unit Economics

Useful operating proxy:

    Intelligence Productivity =
      Economic value created or cost avoided
      --------------------------------------
      all-in intelligence execution cost

All-in execution cost can include inference, energy, model/API cost, data retrieval, orchestration, human oversight, validation, error/rework, and downstream execution.

This is closer to task ROI than accounting ROIC, but can reveal direction before financial statements do.

### 2.3 Marginal I-ROIC

The key reinvestment question:

    Marginal I-ROIC =
      Δ incremental economic profit
      -----------------------------
      Δ intelligence-related capital

Average returns can look excellent while marginal opportunities are already deteriorating.

## 3. The conversion chain

    Energy
      ↓
    Compute
      ↓
    Model / Intelligence
      ↓
    Routing + Memory + Context
      ↓
    Intelligence Sink
      ↓
    Action / Execution
      ↓
    Gross Value Created
      ↓
    Capture
      ↓
    Incremental NOPAT
      ↓
    Feedback / Reinvestment

Each transition can leak value.

## 4. Intelligence Sink quality

Evaluate a sink on at least eight dimensions.

- **Value density** — how valuable is a correct unit of intelligence here?
- **Actionability** — can intelligence actually cause a decision, transaction, code change or physical action?
- **Proprietary access** — can competitors reach the same sink equally easily?
- **Capture rate** — how much created surplus remains with the firm?
- **Validation burden** — how much review is required before action?
- **Feedback richness** — does execution generate proprietary information that improves the next cycle?
- **Repeatability** — is this one-time work or a recurring stream of decisions?
- **Reinvestment runway** — how much additional intelligence can be profitably absorbed before marginal returns fall?

## 5. Capture Rate

Conceptually:

    Capture Rate =
      Economic value retained by the company
      --------------------------------------
      Gross economic value created by intelligence

High gross productivity with low capture can still be a weak investment.

Value can leak through price competition, customer bargaining power, labor capturing productivity gains, upstream compute scarcity, regulation, commoditized output, or easy switching.

## 6. Feedback Loop Strength

A sink becomes more defensible when use improves future use.

    Intelligence
      → Outcome
      → Proprietary observation
      → Memory / data / workflow update
      → Better next decision
      → More usage

A loop should be tested for exclusivity, persistence, transferability, latency, quality, and whether competitors can purchase equivalent data.

"More data" is not automatically a moat.

## 7. Capital and cost decomposition

For each company, separate:

### Intelligence production
- training;
- inference infrastructure;
- energy;
- model R&D.

### Intelligence routing
- context;
- memory;
- orchestration;
- agent runtime;
- tool access;
- observability.

### Validation
- human review;
- tests;
- simulation;
- compliance;
- safety systems.

### Execution
- software actions;
- sales/service systems;
- robotics;
- vehicles;
- factories;
- logistics.

A cheap model connected to an expensive validation/execution system may still have poor I-ROIC.

## 8. Research dashboard

When possible track:

- cost per successfully completed task;
- all-in cost per economic outcome;
- human intervention rate;
- validation/rework rate;
- latency;
- utilization;
- incremental revenue;
- cost savings;
- asset turnover changes;
- margin changes;
- incremental NOPAT;
- intelligence-related invested capital;
- marginal I-ROIC;
- capture rate;
- reinvestment runway.

The dashboard should evolve as disclosure improves.
