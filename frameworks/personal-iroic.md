# Personal I-ROIC Framework

Personal I-ROIC applies the same logic to an individual.

## 1. The wrong optimization

Traditional career optimization asks:

> How much is one hour of my labor worth?

The AI-native question is:

> How much durable productive capacity can one hour of my judgment direct?

The goal is not maximum activity. The goal is leverage over intelligence, capital and organization.

## 2. Personal I-ROIC

A useful conceptual form:

    Personal I-ROIC =
      durable value created with machine intelligence
      -----------------------------------------------
      attention + time + capital + compute + oversight

This is not an accounting ratio. It is an allocation framework.

## 3. Personal sink quality

A personal Intelligence Sink is attractive when work creates an asset that persists after the task ends.

High-quality examples can include:

- owned software / businesses;
- reusable knowledge;
- audience and distribution;
- durable relationships;
- investment research and capital;
- automated workflows;
- an agent organization with persistent memory.

Low-quality sinks consume intelligence but leave little durable residue.

## 4. The transition

A possible path:

    Human Worker
      → AI Operator
      → Agent Organization Owner
      → Business / Asset Owner
      → Capital Allocator

The transition is about ownership, not status.

## 5. Weekly allocation review

A practical review should ask:

- Where did my attention go?
- Where did AI compute/tokens go?
- What persistent asset was created?
- What had the highest observed return?
- What work should be delegated or automated next?
- Which asset deserves more capital next week?
- Which activity was merely consumption?

## 6. Compounding

The personal system becomes stronger when each cycle leaves behind:

- better memory;
- better workflows;
- stronger distribution;
- more capital;
- more owned assets;
- better agents;
- better decision records.

A one-time productivity boost is useful. A compounding system is more important.
