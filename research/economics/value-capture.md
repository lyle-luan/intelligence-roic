# Intelligence Value Capture

## 1. Value creation is not value capture

AI can create large social value while the intelligence provider captures little of it.

For investment, the relevant chain is:

    Capability
      → Product / workflow
      → Outcome
      → Gross economic surplus
      → Bargaining / competition
      → Captured profit
      → Reinvestment

Every arrow matters.

## 2. Where surplus can settle

### Compute layer

Can capture value when hardware or capacity is scarce.

### Model layer

Can capture value when capability, reliability, brand or integration is differentiated.

### Orchestration / memory layer

Can capture value when switching destroys accumulated context, workflow state or operating history.

### Application / workflow layer

Can capture value when it owns the job-to-be-done and customer relationship.

### Endpoint / asset layer

Can capture value when intelligence controls scarce physical or digital assets.

### Customer / consumer

Can capture much of the surplus if competition rapidly passes productivity gains through as lower prices or better products.

## 3. The ownership test

For every claimed moat, ask:

- Who owns the customer?
- Who owns the memory?
- Who owns the feedback?
- Who owns the action right?
- Who owns the physical endpoint?
- Who can switch model providers?
- Who controls pricing?
- Who bears validation liability?

The answers often matter more than model benchmark rank.

## 4. Recursive advantage

The strongest systems may have a recursive structure:

    More intelligence use
      → more proprietary outcome data
      → better future allocation
      → more value
      → more capital available for intelligence

This is an I-ROIC compounding loop.

## 5. Failure mode

If intelligence use creates no proprietary residue, competitors can buy equivalent models, and customers can switch cheaply, high current productivity may still fail to create a durable moat.
