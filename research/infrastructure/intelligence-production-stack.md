# Intelligence Production Stack

## 1. Factory view

An AI stack can be analyzed as a factory:

    Power
      → Data center
      → Accelerators
      → Networking / storage
      → Model runtime
      → Routing / context / memory
      → Useful intelligence

The output should not be measured only as tokens.

The economically relevant output is closer to:

- successfully completed tasks;
- validated decisions;
- accepted code;
- converted customers;
- solved research steps;
- autonomous miles / actions;
- physical work completed.

## 2. Factory ROIC

Infrastructure economics depend on:

- capital cost;
- utilization;
- energy cost;
- depreciation;
- model efficiency;
- software scheduling;
- workload mix;
- pricing;
- customer retention;
- residual hardware value.

Peak benchmark throughput can coexist with poor capital returns if utilization or pricing is weak.

## 3. The downstream dependency

Compute is valuable because something downstream can productively consume intelligence.

Therefore infrastructure research must connect capacity to end sinks.

A temporary compute shortage can create high rents. Long-run valuation must ask what happens when supply expands and intelligence efficiency improves.

## 4. Software around compute

Potential durable value may exist above raw hardware in:

- scheduling;
- routing;
- semantic caching;
- observability;
- memory / KV management;
- metering;
- workload placement;
- enterprise workflow integration.

These layers should be tested for real switching cost rather than assumed to be moats.
